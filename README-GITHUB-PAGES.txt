DMSP ENGINEERING WEBSITE

This package is ready for GitHub Pages. All HTML pages, styles, scripts and image assets are included.

DEPLOY
1. Create or open your GitHub repository.
2. Upload the CONTENTS of this folder directly into the repository root.
   index.html must sit at the repository root. The assets folder must sit beside it.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site.

IMPORTANT
- Keep the assets folder name lowercase and preserve every filename exactly as supplied.
- Do not upload the ZIP itself. Extract it first, then upload its contents.
- This is a static website. The contact links work, but no server-backed enquiry form is included.
- Custom domain can be connected later through Settings > Pages.
